# Браслет, анализирующий речь на наличие слов-паразитов

### Цель и практическая направленность:
Целью проекта было создание прототипа носимого на руке устройства для улучшения качества речи носителя. Практическая задача - детекция слов-паразитов в речи конкретного человека в реальном времени и отклик в виде вибрации и индикации слова на дисплее. 


### Hardware:
Контроллер: `ESP 32-S3-Zero`

Микрофон: `INMP441`

Аккумулятор: `3.7 В, 320 мАч`

Контроллер питания: `TP4056`

Дисплей: `OLED`

Подлючение осуществлялось по `WebSocket`

Код для работы микроконтроллера: [esp32.ino](esp32.ino)

## Результат:
Был создан работающий прототип устройства, который успешно идентифицирует голос носящего браслет человека и сигнализирует о найденных словах-паразитах. В ходе тестирования уверенность идентификации голоса владельца составила около 0.8 на тестовых записях, однако при обработке звука в реальном времени уже с микрофона браслета уверенность модели снижалась, особенно при шепоте и сильной окружающей зашумленности. Проблема заключается в недостатке данных для обучения модели и помехах, возникающих при передаче и записи аудио.
